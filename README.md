# spoken-script-critical-reviewer

一个用于**批判性审查并重构中文口播稿**的 Agent Skill。

## 它解决什么问题

很多“口播优化”只会：
- 换标题；
- 加钩子；
- 变口语；
- 删废话；
- 强行加情绪。

这个 Skill 重点解决更底层的问题：
- 中心问题到底是什么；
- 谁为什么需要听；
- 入口是否真的与用户相关；
- 正文有没有认知推进；
- 观点有没有被证明；
- 案例有没有过度外推；
- 情绪、故事、反差是否只是包装；
- 结尾有没有形成新的判断；
- 如何改，以及为什么这样改。

## 典型使用方式

```text
请使用 spoken-script-critical-reviewer 审查这篇口播稿。
重点看逻辑、论证和传播入口，按默认完整模式输出。
```

也可以指定模式：

```text
只审不改，重点看逻辑漏洞。
```

```text
保守修改，尽量保留我原来的案例和语气。
```

```text
强重构，目标是 2 分钟知识型短视频，但不要为了传播牺牲严谨性。
```

```text
这是一份 SRT。先忽略时间码审查，再给连续口播改稿。
```

## 设计原则

1. **诊断优先于评分**：P0/P1/P2 比 82 分、91 分更能指导修改。
2. **批评必须落到原文**：每条问题必须说明原文位置和观众后果。
3. **结构优先于措辞**：中心问题和论证不成立时，不浪费精力先润色。
4. **不制造事实**：证据不足时标注待核验，不虚构数据。
5. **传播不等于煽情**：入口负责进来，逻辑和证据负责留下来。
6. **改稿还要教学**：解释“改了什么、为什么”，帮助作者形成自己的审稿能力。

## V2 新增能力

真实口播稿测试后，V2 增加了一层专门的**逻辑风险扫描**：

1. 概念偷换；
2. 结论升级；
3. 个案外推；
4. 假二选一；
5. 相关关系被写成因果关系。

同时新增两条传播审查原则：

- **内容复杂度 ≠ 入口复杂度**：允许内容深入，但入口应让目标用户快速知道“这跟我有什么关系”。
- **大入口，窄承接**：可以用大众问题扩大入口，但正文必须回到目标人群和专业价值，避免“播放变大、账号变散”。

V2 还要求审稿时对照：

```text
作者开头要证明什么
→ 正文证据最多支持什么
→ 结尾最终声称什么
```

用于捕捉那些“每一句单看都顺，但整篇论证悄悄变了”的稿件。


## V3 新增能力

第二轮真实口播稿测试后，V3 将“五大逻辑风险扫描”升级为**七大逻辑风险扫描器**，新增：

6. **类比越界**：A 与 B 在某一点相似，不等于 A 的整套规律可以迁移到 B。Skill 会区分类比是“帮助理解”，还是已经被作者拿来“替代证明”。
7. **目标—手段反噬**：检查作者采用的手段，会不会恰恰强化最终想消除的问题；尤其关注短期有效、长期反向强化，以及有没有退出机制。

V3 的逻辑审查因此变成：

```text
概念偷换
+ 结论升级
+ 个案外推
+ 假二选一
+ 相关→因果
+ 类比越界
+ 目标—手段反噬
```

其中“目标—手段反噬”会额外检查：

```text
最终目标
→ 当前手段
→ 短期效果
→ 长期副作用 / 依赖
→ 是否仍然接近最终目标？
```

这让 Skill 不只检查“这句话证明了吗”，还开始检查“这套方法即使短期有效，会不会长期把事情带向相反方向”。
