# 默认输出模板

## 1. 一句话总诊断

> 这篇稿子最大的优点是 ___；目前最大的结构问题是 ___，它会导致 ___。

不要为了平衡而硬夸。若稿子确实存在严重问题，直接准确说。

## 2. 先还原原稿逻辑

- **主题**：
- **中心问题**：
- **核心结论**：
- **目标受众**：
- **为什么关心**：
- **核心冲突**：
- **当前论证路径**：A → B → C
- **希望产生的认知变化**：从 ___ 变成 ___

## 3. 逻辑风险快速扫描（观点/知识/方法论稿必做）

用精简列表给出存在的风险，不要为了凑数硬报问题：

- **概念偷换**：有 / 无；发生在哪里？
- **结论升级**：有 / 无；正文最多支持什么，结尾说成了什么？
- **个案外推**：有 / 无；案例被外推到了什么程度？
- **假二选一**：有 / 无；哪两个本可同时成立的东西被强行对立？
- **相关→因果**：有 / 无；是否把先后/共变写成确定因果？
- **类比越界**：有 / 无；是否从“某一点相似”跳到了“整套规律适用”？
- **目标—手段反噬**：有 / 无；当前手段是否可能强化最终想消除的问题？

若七项都没有明显问题，可以一句话说明“未发现核心逻辑风险”，不要输出七段空话。

## 4. 优先级问题清单

### [P0] 问题标题
- **原文**：“……”
- **问题**：
- **为什么是问题**：
- **观众后果**：
- **修改方向**：
- **示例**：“……”

重复若干项，按重要度排序。

## 5. 建议重构

```text
入口
↓
问题
↓
场景/案例
↓
第一层解释
↓
冲突/反常识
↓
机制
↓
证据/边界
↓
结论
```

随后用 3–8 条解释每个节点承担什么作用。

## 6. 完整修改版

直接给可朗读稿件。不要把分析说明混入口播正文。
